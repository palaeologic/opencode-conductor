# Generic project guidance template

`AGENTS.md` is an optional, vendor-neutral starter for project or subtree guidance.

The installer offers to copy it into a directory chosen by the user when running interactively. For automation:

```sh
bash bin/install-opencode-conductor.sh --seed-agents /path/to/project-or-subtree
```

The operation never overwrites an existing `AGENTS.md`. Edit the seeded file immediately so its project map and verification table describe real repository behavior.
